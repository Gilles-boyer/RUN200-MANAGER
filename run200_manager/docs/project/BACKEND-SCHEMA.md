**Existant vérifié dans le dépôt :** `pilots.license_number` est un `varchar(6)` unique, sans catégorie, année ni échéance ; `race_registrations` relie pilote et course, et `races.race_date` donne la date de référence. `checkpoint_passages` porte `ADMIN_CHECK`, mais aucun passage ne prouve une licence RCCR. **Table proposée `race_registration_license_checks` (une ligne courante par inscription) :** `id` bigint PK ; `race_registration_id` bigint FK unique vers l'inscription ; `license_number_snapshot` varchar(6) ; `pilot_first_name_snapshot` et `pilot_last_name_snapshot` varchar(255) ; `race_date_snapshot` date ; `required_license_code_snapshot` varchar(32) ; `result` varchar(20) dans `{valid,invalid,needs_review}` ; `license_type_observed` varchar(32) nullable ; `license_year_observed` smallint nullable ; `license_state_observed` varchar(20) nullable (`active|inactive|expired|suspended|unknown`) ; `identity_matches` bool nullable ; `license_number_matches` bool nullable ; `valid_for_race_date` bool nullable ; `valid_until` date nullable si affichée par la source ; `source` varchar(32) dans `{verification_ffsa,ligue_ffsa,licence_ffsa,official_ffsa_document}` représentant la source tentée ou lue ; `source_access_status` varchar(20) dans `{consulted,unavailable,incomplete}` pour distinguer une preuve lue d'une simple tentative ; `reason_code` varchar(40) nullable ; `note` varchar(500) nullable ; `checked_at` timestamp ; `checked_by` FK nullable vers `users` avec `nullOnDelete` pour ne pas bloquer la purge du compte staff ; `revision` unsigned int pour protéger deux décisions rapprochées ; `created_at`, `updated_at`. `race_registration_id` unique suffit pour la recherche de la liste ; index additionnel seulement après mesure.
